Proyecto CI/CD y arquitectura AWS
Este repositorio utiliza una estrategia de **Ramas de Características (Feature Branches)** basada en GitFlow. Cada nueva funcionalidad, componente o documento se desarrolla en una rama independiente (ej. `feature/frontend`, `feature/docker`) que luego se integra a la rama `main` mediante Pull Requests.
El objetivo de este repositorio es implementar un ciclo completo de DevOps, automatizando la construcción de imágenes con GitHub Actions y preparando el despliegue para una arquitectura multinivel en AWS.
